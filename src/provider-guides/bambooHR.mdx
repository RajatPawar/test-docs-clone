## What's supported

### Supported actions

This connector supports:
- [Read Actions](/read-actions), including full historic backfill.

### Supported Objects

The BambooHR connector supports the following objects:
- employees (read)
- jobs (read)
- applications (read)
- requests (read)
- schedules (read)
- timesheet_entries (read)

## Using the connector

This connector uses Basic Auth, which means that you do not need to set up a Provider App before getting started. (Provider apps are only required for providers that use OAuth2 Authorization Code grant type.)

To start integrating:
- Create a manifest file (see the [samples](https://github.com/amp-labs/samples)).
- Deploy it using the [amp CLI](/cli/overview).
- If you are using Read Actions, create a [destination](/destinations).
- Embed the [InstallIntegration](/embeddable-ui-components#install-integration) UI component. It will prompt the customer for their username and password.
- Start using the connector!
